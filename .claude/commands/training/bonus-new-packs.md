## 1. Doddle Affiliate OS (`doddle.affiliate.*`, `/affiliate:*`)

Niche sites and programmatic comparison portfolios: niche → keywords → content → links → revenue.

| Skill | When |
|-------|------|
| `affiliate-niche` | Picking or killing a niche |
| `affiliate-keywords` | Best-X / vs portfolios at scale |
| `affiliate-content` | Review briefs with E-E-A-T + disclosure |
| `affiliate-links` | Gap + outreach without spam |
| `affiliate-revenue` | EPC lift via CRO |

Rule: never invent volumes, specs, or EPC. Tool or NOT AVAILABLE.

## 2. Doddle DevOps OS (`doddle.devops.*`, `/devops:*`)

First non-marketing pack (10 skills, derived from *Linux System Administration*, Paul Cobbaut, GFDL 1.3): processes, storage, LVM/RAID, boot/systemd, cron/logging, monitoring, packages, networking/ssh, kernel, backup. Same v2 scaffold (SKILL.md + blueprint.yaml, validator-gated) — proof packs work outside marketing.

## 3. Travel Growth Composition (`doddle.travel.growth`, `/travel:growth`)

The first `call`-node composition: `local-gbp` + `local-reviews` + `travel-itinerary` + `programmatic-seo` in one DAG. Study its blueprint when learning cross-pack `call` mechanics (inputs mapping with `$vars`, depth ≤3, no self-call).

## 4. Deepened packs

- **SaaS (14):** onboarding, paywall, emails, analytics, dunning + comparison, reviews, security, docs. Dunning exercises the `stripe` stub — expect NOT AVAILABLE until live.
- **B2B (16):** list, deliverability, linkedin, coldcall, discovery, demo, rfp, negotiation + onboarding, qbr, referrals.
- **GTM (14):** icp, messaging, pricing, launch, enablement + plg, intl, compete. Orchestration layer — most nodes are `call`s into marketing, B2B, and sales.

## 5. Velocity vs enterprise routing

Sales pack = short-cycle velocity (`domains: [velocity, smb]`). B2B discovery/negotiation = enterprise/agency (`domains: [enterprise, agency]`). When a request is ambiguous, ask which motion before picking a skill — this is the router's confidence rule in action.

## 6. What still runs degraded

`google-business-profile` and `stripe` are stubs: skills binding them show ⚠️ NOT AVAILABLE with setup steps. An honest "not available" beats a fabricated number — the data-reliability rule, machine-enforced.

# Quick Assessment Checklists

Use these checklists to quickly assess marketing areas. Each takes 5-10 minutes.

---

## Website CRO Assessment

### Quick Audit (5 minutes)
- [ ] Can visitors understand what you do in 5 seconds?
- [ ] Is there one clear primary CTA?
- [ ] Is the CTA above the fold?
- [ ] Are there 3 or fewer navigation items?
- [ ] Is mobile experience good?
- [ ] Does page load in under 3 seconds?
- [ ] Are there customer logos/testimonials?
- [ ] Is there a clear value proposition?

### Score
- 8/8: Excellent
- 6-7: Good, optimize weak areas
- 4-5: Needs work, prioritize top issues
- <4: Major redesign needed

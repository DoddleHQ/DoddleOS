# Expected Output Format Guide

Standard formats for marketing skill outputs. Use these templates for consistency.

---

## General Output Structure

All marketing outputs should follow this structure:

```
## [Task Title]

### Executive Summary
[2-3 sentences summarizing the recommendation]

### Situation Analysis
[Current state, context, key findings]

### Recommendations
[Specific, actionable recommendations]

### Implementation Plan
[Steps, timeline, resources]

### Measurement
[How to track success]

### Next Steps
[Immediate actions to take]
```

## How to Use These Templates

1. **Copy the relevant template** for your task
2. **Fill in the sections** with specific information
3. **Remove sections** that don't apply
4. **Add sections** if needed for your specific case
5. **Save as documentation** for future reference

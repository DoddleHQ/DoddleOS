## Collaboration Patterns

### Pattern 1: Campaign Launch

```
User Request: "Launch new product campaign"

Flow:
1. researcher → Market analysis, competitor research
2. brainstormer → Campaign concepts
3. planner → Campaign plan, timeline
4. copywriter → Messaging, content
5. email-wizard → Email sequences
6. attraction-specialist → Landing pages, SEO
7. conversion-optimizer → CRO review
8. project-manager → Coordination
9. brand-voice-guardian → Brand check
10. analytics-attribution → Measurement setup
```

### Pattern 2: Content Creation

```
User Request: "Create blog post for lead gen"

Flow:
1. seo-specialist → Keyword research
2. researcher → Topic research
3. copywriter → Content creation
4. conversion-optimizer → CTA optimization
5. docs-manager → Documentation
6. attraction-specialist → SEO optimization
```

### Pattern 3: Conversion Optimization

```
User Request: "Improve landing page conversion"

Flow:
1. conversion-optimizer → Audit current page
2. researcher → Best practices
3. copywriter → Copy improvements
4. seo-specialist → SEO check
5. brand-voice-guardian → Brand consistency
6. ab-test-setup → Testing plan
7. analytics-attribution → Measurement
```

### Pattern 4: Email Campaign

```
User Request: "Create email nurture sequence"

Flow:
1. lead-qualifier → Audience segmentation
2. email-wizard → Sequence design
3. copywriter → Email copy
4. conversion-optimizer → CTA optimization
5. brand-voice-guardian → Brand check
6. analytics-attribution → Tracking setup
```

### Pattern 5: Competitive Response

```
User Request: "Competitor just launched feature"

Flow:
1. researcher → Competitor analysis
2. attraction-specialist → Positioning update
3. copywriter → Response messaging
4. email-wizard → Customer communication
5. sales-enabler → Battlecard update
6. docs-manager → Documentation update
```

## Agent Handoff Protocol

### When to Hand Off

| Situation | From Agent | To Agent |
|-----------|------------|----------|
| Need market data | Any | researcher |
| Need creative ideas | Any | brainstormer |
| Need content written | Any | copywriter |
| Need SEO review | Any | seo-specialist |
| Need brand check | Any | brand-voice-guardian |
| Need conversion review | Any | conversion-optimizer |
| Need project coordination | Any | project-manager |
| Need documentation | Any | docs-manager |

### Handoff Format

```
## Handoff: [From Agent] → [To Agent]

### Context
[Brief description of what was done]

### Deliverables
[List of completed items]

### Questions/Decisions
[Any decisions needed from receiving agent]

### Next Steps
[What the receiving agent should do]
```

## Collaboration Best Practices

### Communication
1. **Be specific** - Clear task descriptions
2. **Set deadlines** - When is it needed?
3. **Provide context** - Background information
4. **Use templates** - Consistent formats
5. **Document decisions** - Why choices were made

### Quality
1. **Review before handoff** - Self-check first
2. **Follow brand guidelines** - Consistency matters
3. **Optimize for conversion** - Business outcomes
4. **Track performance** - Measure results
5. **Iterate based on data** - Continuous improvement

### Efficiency
1. **Work in parallel** - When possible
2. **Use shared documents** - Real-time collaboration
3. **Automate handoffs** - Reduce friction
4. **Track progress** - Visibility for all
5. **Celebrate wins** - Acknowledge contributions

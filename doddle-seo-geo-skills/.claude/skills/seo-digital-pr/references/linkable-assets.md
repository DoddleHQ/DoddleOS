# Linkable assets & outreach templates

Reference for `seo-digital-pr`. All judgement here is `advisory`. No outlet metric is ever
assumed; verify with `doddle.tool.v1.ahrefs.backlinks` or leave it `not checked`.

## Asset types and when they earn links

| Asset | What it is | Earns links when… | Effort |
|-------|------------|-------------------|--------|
| Data study | Original analysis of a dataset the brand owns | The finding is surprising and citable | High |
| Survey | Primary research with a named sample | The headline stat is newsworthy and the method is honest | High |
| Index / benchmark | Ranked table across a market | It gives a journalist a ready-made hook | Medium |
| Calculator / tool | Interactive utility | It answers a recurring question better than words | High |
| Map / visualisation | Geographic or relational view | It is genuinely hard to reproduce | Medium |
| Reference / glossary | Definitive explainer | It becomes the canonical citation for a term | Medium |
| Template / checklist | Downloadable utility | It saves the reader real work | Low |

### Linkability criteria

Before building, an idea must pass all four:

1. **Newsworthy** — a journalist could write a headline from it.
2. **Data-backed** — a verifiable number or method, not an opinion.
3. **Quotable** — a single sentence an editor can lift.
4. **Relevant** — it fits the beat of the outlets you will pitch, and the page you want linked.

If it fails one, change the idea or drop it. Do not build first and look for a reason later.

## Outreach list criteria

- Same market and language as the target page.
- Has covered the topic or a near-topic recently (verify by reading, not by assuming).
- Editorial format — articles and resource pages, not link directories or paid placements.
- No metric is quoted unless the live tool returns it.

## Journalist / HARO-style pitch template

```
Subject: <specific hook> — <credible credential>

Hi <name>,

<One sentence: the quotable fact, with its source and date.>

I can provide <the data / expert comment / asset> on <topic>. <One line of credentials.>

<Link to the asset or the data.> Happy to send the underlying figures.

<Name>, <role>, <brand>
```

Rules that decide whether the pitch becomes a link:

- Reply inside the deadline; speed beats polish.
- Lead with the fact, not the brand.
- One ask, one link.
- No attachments unless requested.
- Follow up once, then stop.

## What makes coverage earn a link (and what does not)

- **Earns an editorial link:** the journalist cites the asset or the data in the body copy.
- **May mention without linking:** an unlinked brand mention — monitor and request the link once.
- **Does not count as earned links:** press-release wire syndication, sponsored posts, directory
  listings, comment spam.

Record each piece of coverage and its link status as a manual item; only move a number into the
report when the live tool or the user supplies it.

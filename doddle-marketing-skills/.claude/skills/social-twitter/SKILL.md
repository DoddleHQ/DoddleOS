# Social: Twitter/X
Social execution for Twitter/X — conversation-driven content, threads for depth, media for reach, profile authority for trust. Cross-reference `social-media`; this applies the Twitter layer.

## When to Use This Skill
- Building professional/news presence on Twitter/X
- Thread-based depth content
- Conversation-driven engagement (replies, quote-tweets)
- Awareness/top-of-funnel for B2B/professional audiences

---

## Core Framework (Twitter/X-Specific)
1. Confirm goal fits Twitter/X (awareness, authority, conversation). For procurement/leads → redirect to LinkedIn / `b2b.proposals`.
2. Lock pillars: news/professional insight (educational/authoritative) + conversation starters + promotional (capped at 10%). Ratio: 50% insight / 30% conversation / 10% promotional / 10% entertaining.
3. Create native assets: thread (hook line + 3-7 tweets + CTA), short-form update (1-2 lines + image/video + link in comments), conversation reply templates. Apply `approve_content` gate before `distribute`.
4. Cadence: 3-5x/day; best windows: Wed-Fri 9am / 12pm / 5pm. Lock in `assets`. Apply gate.
5. Growth: reply velocity (first 30 min critical); collaboration accounts; paid amplification (`paid-advertising`); cross-promotion (`email-marketing`).

## Anti-Patterns (Twitter/X-Specific)
| Anti-Pattern | Fix |
| Repurposing unchanged | Rewrite/reformat: short-form + media; no link-heavy body |
| No hook line / slow thread opening | Lock hook in thread assets |
| All promotional / no conversation | Lock pillar ratio; respond to all comments within 1 hour (`social-engagement`) |
| Ignoring first 30 min | Monitor and respond; velocity determines reach |

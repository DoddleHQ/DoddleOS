# Social: Facebook
Social execution for Facebook — community/group presence, events, video watch-time, emotional/inspirational content, local/business credibility. Cross-reference `social-media`; applies Facebook layer.

## When to Use This Skill
- Building local/community presence; events; group engagement
- Video content for broad audiences (35-65+)
- Emotional/inspirational content; community spotlight and UGC features

---

## Core Framework (Facebook-Specific)
1. Confirm goal fits Facebook (local/community/awareness for broad audiences; groups for retention; events for conversion). For B2B/procurement → redirect (`social-linkedin`, `b2b.proposals`).
2. Lock pillars: community/inspirational 40% + educational 30% + entertaining 20% + promotional 10%. Ratio native to Facebook's emphasis on comments/shares/video.
3. Create native assets: video (2-5 min, captions always), event details, group content, community spotlight. Lock in `assets`. Apply `approve_content` gate.
4. Cadence: 1-2x/day (Wed-Fri 1-4pm best). Lock schedule. Apply gate.
5. Growth: group/community engagement; collaboration accounts; events promotion; paid amplification (`paid-advertising`); cross-promotion (`email-marketing`). Apply gate.

## Anti-Patterns (Facebook-Specific)
| Anti-Pattern | Fix |
| Repurposing unchanged | Adapt to Facebook native format (video, groups, events, emotional/inspirational content) |
| No group/community management | Lock group/community cadence in `plan` |
| All promotional | Lock pillar ratio (value-heavy, emotional/inspirational) |
| No captions | Always include captions (video dominance) |
